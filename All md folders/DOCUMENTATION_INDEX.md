## Quick Reference

### Key Technologies
- **Backend**: Node.js, Express.js, Sequelize ORM
- **Frontend**: React 18, Vite, Tailwind CSS
- **Database**: MySQL 8.0+
- **Authentication**: JWT + bcrypt
- **QR Codes**: qrcode library

### Key Features
- 10 complete modules
- 55 API endpoints
- 24 frontend routes
- 9 database models
- Role-based access control (5 roles)
- Real-time analytics and reporting
- CSV/PDF export
- QR code generation and scanning
- PDF generation for passes
- Gate log tracking

### Key Roles
- **Student**: Apply for passes, view status
- **Coordinator**: Approve LONG_LEAVE passes
- **Hostel Staff**: Approve all passes, manage students
- **Security**: Scan QR codes, track gate logs
- **Admin**: Manage users, view reports
