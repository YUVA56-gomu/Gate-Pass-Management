## Core Features

### QR Scanning
- Scan QR tokens with validation
- Verify token exists, is active, and not expired
- Validate pass is APPROVED
- Implement scan logic (OUT → IN → COMPLETED)
- Create gate logs with transaction safety
- Return detailed scan results

### Gate Logging
- Create OUT log on first scan
- Create IN log on second scan
- Return COMPLETED on third+ scan
- Store scan timestamp and security staff
- Track scan status (VALID/INVALID/EXPIRED)

### Dashboard
- Today's Scans: Total scans count
- Students Outside: OUT without IN
- Completed Passes: OUT + IN
- Recent Activity: Last 10 scans

- Color-coded status indicators
- Auto-focus after scan

### Logs Viewer
- Filter buttons: ALL, OUT, IN, TODAY
- Logs table with all details
- Summary cards (Total, OUT, IN)
- Loading and empty states

## Scan Logic

### First Scan
```
Input: Valid QR token, no OUT log exists
Output: Create OUT log, return "OUT"
```

### Second Scan
```
Input: Valid QR token, OUT log exists, no IN log
Output: Create IN log, return "IN"
```

### Third+ Scan
```
Input: Valid QR token, OUT and IN logs exist
Output: No new log, return "COMPLETED"
```
